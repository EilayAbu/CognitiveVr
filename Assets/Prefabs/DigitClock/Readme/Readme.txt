Description

 This is a digit clock model that displays current time.
	
Features

  * High performance
  * Easy use
  * One material with one custom shader
  * Adjustable case and face material characteristics (metallic, smoothness, color)
  * Adjustable time

Render pipelines
  
  * Build-in render pipeline 

Minimum Requirements

  Software

    Unity 2020.3.10f1 or higher

Quick Guide Install installation.
  
  1) With opened scene > Import Package > Custom Package => locate this package => <DigitClockPackage>
  2) Import all package items.
  3) A new folder <DigitClock> has appeared in Assets.
  4) You can open scene <DemoScene> DigitalClock/Scenes/DemoScene to check how it works or you can add <DigitClock01> prefab to your scene and test it
  5) You can duplicate the digit clock as much as you like and adjust days and minutes to create a current time offset with DigitClock script inputs.
  6) You can customize case and face material characteristics (metallic, smoothness, color).
  7) To have a different material settings duplicated clocks you need to duplicate material and apply it to a new one
